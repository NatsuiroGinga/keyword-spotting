# Temporary Scripts Directory

This directory contains temporary debug and test scripts that were created during the development process.

## Debug Scripts
- `debug_*.py` - Debugging scripts for various components (buffer, MLP, suffix extraction, etc.)

## Test Scripts
- `test_*.py` - Temporary test scripts for testing specific features

## Other
- `compare_models.py` - Model comparison utility
- `test-hf-repo/` - HuggingFace repository testing
- `hf_upload/`, `models/` - Temporary directories

These scripts are not part of the main codebase and may be outdated.
